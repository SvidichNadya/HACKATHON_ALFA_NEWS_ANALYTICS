# Материалы Центра макроэкономических исследований Альфа-Банка

Положите сюда оригинальные PDF / DOCX / MD / TXT из приложения 2 кейса. При старте (`python -m radar.cli init`) они будут
проиндексированы как аналитика банка (с локаторами «стр., абз.») и появятся в выводах вместо учебных образцов.
Файл `README.md` не импортируется.
