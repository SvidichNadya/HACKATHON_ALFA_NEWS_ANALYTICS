# Alfa News Intelligence

Демонстрационный аналитический веб-сервис для перехода от новостного потока к проверяемым бизнес-сигналам. Данные по умолчанию синтетические: они нужны для демонстрации UX и не являются реальными публикациями или рекомендациями Альфа-Банка.

## Быстрый запуск (Windows)

1. Установите и запустите Docker Desktop с поддержкой Docker Compose v2.
2. Запустите `run.bat` двойным щелчком или из командной строки.
3. Откройте http://localhost:8000.

При первом запуске `run.bat` создаёт `.env` из `.env.example`, затем Docker Compose поднимает PostgreSQL, ждёт успешного healthcheck, собирает веб-образ, применяет миграции, добавляет демонстрационные данные и запускает Django. Повторный запуск использует те же контейнеры и том данных; миграции и seed безопасны для повторного выполнения.

## Команды

- Запуск/пересборка: `docker compose up --build -d`
- Логи: `docker compose logs -f`
- Остановка без удаления данных: `docker compose down`
- Полный сброс БД (ОСТОРОЖНО, удаляет локальные данные): `docker compose down -v`
- Проверка состояния: `docker compose ps`

## Конфигурация

Настройки окружения — в `.env`: секрет Django, режим debug, разрешённые хосты, параметры PostgreSQL и внешний порт. Для реального размещения обязательно задайте уникальный `DJANGO_SECRET_KEY`, `DJANGO_DEBUG=0`, корректный `DJANGO_ALLOWED_HOSTS` и надёжный пароль БД.

## Архитектура

- `config/`: конфигурация Django, URL-маршрутизация и WSGI.
- `analytics/`: доменная модель новостных материалов и бизнес-сигналов, страницы и JSON API.
- `templates/analytics/`: серверный шаблон интерфейса.
- `static/analytics/`: CSS и JavaScript интерфейса.
- PostgreSQL: постоянное хранилище в именованном Docker volume.
- Docker Compose: управляет зависимостями и порядком запуска; web стартует только после успешной проверки готовности БД.

Функциональность источников, реальный сбор новостей, дедупликация, NLP/LLM-анализ, аутентификация и production-hardening — отдельные подключаемые модули следующего этапа. Сейчас интерфейс использует синтетические демонстрационные данные и не заявляет о реальном подключении к новостным источникам.

## Локальный запуск без Docker

Python 3.12+: `python -m venv .venv`, активируйте окружение, `pip install -r requirements.txt`, `python manage.py migrate`, `python manage.py seed_demo`, `python manage.py runserver`. При отсутствии `POSTGRES_HOST` используется SQLite для разработки; Compose запускает PostgreSQL.
